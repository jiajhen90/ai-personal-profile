## 本地同步与版本记录

本仓库使用 Git 记录文件变更；每次保存到仓库都应创建有意义的提交。

```bash
git clone https://github.com/jiajhen90/ai-personal-profile.git
cd ai-personal-profile
git pull --ff-only
# 编辑 README.md 后
git add README.md
git commit -m "docs: 更新个人档案"
git push
```

查看历史：`git log --oneline`，查看某次变化：`git show <提交哈希>`。
需要撤销已提交的修改时，使用 `git revert <提交哈希>`，再执行 `git push`，通过新提交保留原始记录。
网页也可通过 README 的 History 查看历史。Git 记录已提交的文件变更；本地未提交的编辑不会自动记录。
